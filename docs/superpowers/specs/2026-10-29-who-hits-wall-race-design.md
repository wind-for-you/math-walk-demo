# 谁先撞墙 — 多球随机游走竞赛（v2）设计说明

日期：2026-10-29  
状态：待用户审阅  
项目目录：`/workspace/math-walk-demo`  
前置：v1 单球轨迹对比已上线（GitHub Pages）

## 1. 目标与成功标准

### 目标

把「好看但不好看下去」的单球游走，改成 **有悬念、能猜、有结局** 的短视频演示：三球同时随机走，谁先撞上包围壳谁赢。优先竖屏录屏；同一页支持点按换种子重赛。

### 成功标准

- 打开即自动播放一圈约 **24–30 秒**，无需操作即可录竖屏短视频。
- 观众能在 2 秒内看懂「在比谁先撞墙」；撞墙瞬间有明显高潮（定格 + 闪光 + 时间）。
- 同一 `?seed=` 结果可复现（撞墙顺序与时间一致）；点击 / 空格换 seed 重赛。
- 竖屏 9:16 默认构图；文案在上下安全区。

### 非目标（本版不做）

- 可调球数 / 壳半径 UI（参数写死，代码里常量即可）。
- 会动的出口、障碍迷宫、音效、MediaRecorder 内录。
- 后端、登录、公式墙、赌徒破产线玩法。

## 2. 受众与形态

- **主**：自媒体竖屏短视频（旁观、系统录屏）。
- **次**：网页互动（点一下换种子再看一局）。

## 3. 核心玩法

- 三颗颜色不同的球从原点同时出发，各自独立三维轴对齐随机游走（±x ±y ±z，等概率，固定步长）。
- 场景有一固定半径 `R` 的半透明球壳（禁区边界）。
- 球心到原点距离首次 `≥ R` 视为撞墙：该球定格闪光，记录撞墙时刻（秒）。
- 其余球继续走到时限结束，或也撞上。
- 结尾展示三色结果：撞墙时间，或「还在里面」。
- 轻量金句示例：「随机里，迟早有人先撞上。」（可配置文案，不堆公式）

## 4. 时间轴（约 28 秒，可微调）

| 时段 | 内容 |
|------|------|
| 0–2s | 三球叠在圆心；壳淡入；标题「谁先撞墙？」 |
| 2–22s | 三色轨迹同时生长；下方秒数跳动；先撞者定格发光 |
| 22–28s | 排行式结果（颜色点 + 时间 / 仍在里面）；金句；淡出 |
| 重置 | 新 seed（或锁定 seed）进入下一圈 |

自动循环；网页点击 / 空格 = 换 seed 重跑并写入 URL。

## 5. 数学与随机

- 模型：与 v1 相同的六方向轴对齐游走；每球独立 PRNG 流（由主 seed 派生，如 `seed`、`seed+1`、`seed+2`），保证同主 seed 可复现。
- 撞墙判定：`√(x²+y²+z²) ≥ R`（实现可用平方比较避免开方）。
- `R`、步长、步频写死为常量，使「多数 seed 在竞走段内至少一人撞墙」；单测固定若干 seed 断言。
- URL：`?seed=42` 锁定；无参数则每圈新 seed。

## 6. 画面规范

- 背景：沿用深色科技风。
- 壳：半透明球壳（或线框优先清晰度，实现时二选一默认半透明）。
- 三球 / 三色轨迹：高对比三色（如青 / 琥珀 / 品红），轨迹细线生长，撞墙后该色加粗。
- HUD：上标题；下实时秒数 + 三色状态小标签；结尾大结果块。
- 竖屏安全区：上下留白给系统录屏 UI。

## 7. 技术结构（相对 v1）

| 模块 | 变更 |
|------|------|
| `rng` / `walk` | 保留；可派生多路 seed |
| **新增 `race`** | 三球状态、共享 `R`、撞墙时间、排名 |
| `timeline` | intro → race → result → reset |
| `scene` | 壳网格、三色轨迹、撞墙闪光 |
| HUD / `main` | 文案与结果接线；seed URL 行为保留 |
| 测试 | 同 seed 撞墙顺序一致；指定 seed 在 N 步内有人撞墙 |

技术栈不变：Vite + TypeScript + Three.js + Vitest。交付仍走现有 GitHub Pages 流程。

## 8. 验收清单

- [ ] 打开自动播放，单圈约 24–30s 并循环
- [ ] 竖屏可录；标题与结果在安全区
- [ ] 能看懂竞赛；至少常见 seed 下有人撞墙并定格
- [ ] 同 seed 两次撞墙顺序与时间一致；换 seed 结果不同
- [ ] 点击 / 空格换 seed；`?seed=` 可锁
- [ ] `npm test` 通过；`npm run build` 成功

v1「路径长度 vs 位移」演示保留在仓库历史 / 可选分支；本版主线体验切换为「谁先撞墙」。不要求同页双模式开关（YAGNI）。
