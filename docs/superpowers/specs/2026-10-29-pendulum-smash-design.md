# 单摆抄家（v3）设计说明

日期：2026-10-29  
状态：待用户审阅  
项目：`/workspace/math-walk-demo`（原仓库迭代；主体验切换为本玩法）

## 1. 目标

面向自媒体竖屏短视频：用 **带阻尼的单摆** 做出「谁先砸碎花瓶」的悬念。优先录屏；网页可点换参数重赛。

### 成功标准

- 打开自动播约 24–30s 一圈；2 秒内看懂在比谁砸花瓶。
- 三摆长度不同 → 周期不同，可被观众预判又怕猜错。
- 轻阻尼：振幅逐渐衰减；砸中瞬间定格闪光。
- `?seed=` 可复现；点击/空格换 seed 重赛。
- 标题有钩子：《三个单摆，谁先砸碎花瓶？》

### 非目标

- 大角度精确非线性求解 UI、可调阻尼滑条、音效、内录。
- 随机游走 / 谁先撞墙并列为同页双模式（本版主线替换）。

## 2. 物理

- 小角度近似：\(\ddotθ + (b/m)\dotθ + (g/L)θ = 0\)（线性阻尼）。
- 或等价：\(\ddotθ = - (g/L) sinθ - γ \dotθ\)（实现可用 sin，参数取使观感接近小角度）。
- 周期直觉文案：\(T≈2π√(L/g)\)（淡显，不堆公式墙）。
- 三摆长度 \(L_1<L_2<L_3\) 写死常量；同一初始角 \(θ_0\)；\(g\)、阻尼系数 \(γ\) 写死。
- 花瓶：固定世界坐标点；摆球中心距花瓶 ≤ 碰撞半径即「砸中」。

## 3. 时间轴（约 28s）

| 时段 | 内容 |
|------|------|
| 0–2s | 标题；三摆抬到 \(θ_0\) |
| 2–22s | 同时释放；秒数；先砸中定格；可选淡显周期提示 |
| 22–28s | 排行（颜色 + 砸中时间 / 未砸中）；金句；淡出重置 |

## 4. 画面

- 深色场景；三色摆绳+球；花瓶高对比（发光轮廓）。
- HUD：上标题；下秒数与结果；金句「周期看长度，阻尼让热闹收场」。
- 竖屏 9:16 安全区。

## 5. 结构

- 新增 `pendulum.ts`：积分一步、碰撞检测、派生三摆参数（可由 seed 微调长度扰动可选；第一版长度固定、seed 只影响展示微扰或镜头）。
- `timeline`：intro → race → result → reset（可复用相位名）。
- `scene`：绳、球、花瓶；砸中闪光。
- `hud` / `main`：新文案与接线；Pages 流程不变。
