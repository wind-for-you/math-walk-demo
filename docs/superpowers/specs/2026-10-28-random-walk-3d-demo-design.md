# 随机游走 3D 演示小游戏 — 设计说明

日期：2026-10-28  
状态：待用户审阅  
项目目录：`/workspace/math-walk-demo`

## 1. 目标与成功标准

### 目标

做一款面向自媒体的 **数学可视化 / 演示内容**：用干净、科技感的抽象粒子，展示三维随机游走「乱走与铺开」。第一版优先服务短视频录制，同时同一套场景可适配可互动网页与截图轮播。

### 第一版成功标准

- 打开页面后 **自动播放约 15–30 秒循环**（设计锚定 **24 秒**），无需操作即可录一条竖屏短视频。
- 画面为抽象粒子 + 轨迹丝带，深色科技风，适合讲数学本身。
- 同一 seed 可复现；换 seed 可快速产出下一条素材。
- 竖屏（9:16）为默认构图；桌面可横屏预览；高光帧适合截图。

### 非目标（第一版不做）

- 不做自媒体经营模拟（涨粉、爆款经营）。
- 不做多粒子扩散云、障碍碰撞、关卡得分。
- 不做后端、登录、强制内录（MediaRecorder）；音效非必须。
- 不堆扩散方程公式墙。

## 2. 受众与发布形态

- **受众**：自媒体创作者用其作为演示素材；观看者通过画面理解「路径长度 ≠ 位移」。
- **发布**：竖屏短视频（抖音 / 视频号 / 小红书）、可互动网页链接、截图轮播 — **同一套演示、三种导出**。

## 3. 核心体验与时间轴（约 24 秒，可无缝重播）

| 时段 | 内容 |
|------|------|
| 0–2s | 深色空场景；原点出现一颗亮点；角标淡入「随机游走」 |
| 2–18s | 粒子每步随机迈固定步长；半透明轨迹丝带生长；镜头缓慢环绕并微微后拉 |
| 18–22s | 轨迹定格；显示对比：路径长度 ≈ 步数×步长；直线位移 ≪ 路径；细暖色弦连接起点→终点 |
| 22–24s | 淡出到黑；用新随机种子重置，进入下一圈 |

**互动（网页次要能力）**：点击或空格 = 换种子重跑。第一版以自动循环为主。

## 4. 数学规则

- **模型**：三维轴对齐简单随机游走。每步从 6 个方向（±x、±y、±z）等概率选取，步长固定。
- **步数**：约 24 秒内完成 N 步，建议 N ∈ [200, 400]，可配置。
- **统计**：路径长度 = N × 步长；位移 = \|终点 − 起点\|。
- **随机**：可种子伪随机数生成器（PRNG）；同一 seed 轨迹与镜头表现可复现。
- **种子策略**：自动循环每圈使用新 seed（便于连续出素材）；可通过 URL 参数（如 `?seed=42`）锁定 seed，方便复录同一条。

## 5. 画面规范

- **背景**：近黑蓝深空 + 轻微雾感。
- **粒子**：高亮点精灵或小号 mesh。
- **轨迹**：半透明霓虹丝带（青 / 电蓝），随时间衰减透明度（越旧越淡）。
- **对比元素**：起点小锚点；18–22s 出现起点→终点暖色细弦。
- **文案**：无衬线、低对比、不抢主体；竖屏置于上下安全区。

## 6. 技术架构与交付

### 交付形态

- 单页 Web 应用：浏览器打开即播。
- 第一版：本地可运行的静态构建产物 + 启动说明；在线托管链接可后续再加。

### 技术选型

- **Three.js + Vite + TypeScript**
- 渲染：`requestAnimationFrame`；时间轴用轻量状态机（`intro` → `walk` → `compare` → `reset`）
- 轨迹：`Line` 或自定义 buffer 丝带
- 随机：可种子 PRNG 模块

### 模块划分

| 模块 | 职责 |
|------|------|
| `rng` | 种子随机 |
| `walk` | 步进、路径与位移统计 |
| `scene` | 相机、雾、粒子、丝带、弦线 |
| `timeline` | 24 秒阶段与文案显隐 |
| `export-hints` | 竖/横构图与安全区 |

## 7. 风险与后续

- **手机性能**：步数与丝带段数需可降级（减少 N 或轨迹采样）。
- **第二集素材（非本版范围）**：多粒子扩散云；或分屏「随机 vs 直线」对照。

- [ ] 竖屏构图可直接系统录屏
