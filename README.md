# 随机游走 · 谁先撞墙

三颗彩色小球从原点同时出发，各自做三维轴对齐随机游走，比谁先撞上半透明球壳。单圈约 28 秒自动循环，竖屏 9:16 可直接系统录屏。

## 技术栈

Vite + TypeScript + Three.js + Vitest

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址。

```bash
npm test      # 纯逻辑单测
npm run build # 静态产物到 dist/
npm run preview
```

## 玩法与使用

- 打开即自动播放：intro → race → result → reset，共 28 秒循环
- 三球（青 / 琥珀 / 品红）各自独立随机游走；球心到原点距离首次 ≥ 壳半径即「撞墙」
- 撞墙的球定格、轨迹停止生长并闪光；22–26s 展示排行式结果与撞墙时间
- 点击画面或按空格：换 seed 重跑（并写入 URL）
- `?seed=42` 锁定种子：同一 seed 的撞墙顺序与时间可复现，循环时复播
- 无 `seed` 参数时，每圈自动换新 seed
- 默认竖屏 9:16 构图；桌面可拉横窗预览

## 默认参数

| 项 | 值 |
|----|----|
| 循环 | 28s（intro 2s / race 20s / result 4s / reset 2s） |
| 球数 | 3 |
| 壳半径 R | 1.2 |
| 步数 N | 320 |
| 步长 | 0.08 |
| 方向 | ±x ±y ±z 等概率 |

## 验收清单

- [ ] 打开自动播放，单圈约 24–30s 并循环
- [ ] 竖屏可录；标题与结果在安全区
- [ ] 能看懂竞赛；常见 seed 下有人撞墙并定格闪光
- [ ] 同 seed 两次撞墙顺序与时间一致；换 seed 结果不同
- [ ] 点击 / 空格换 seed；`?seed=` 可锁
- [ ] `npm test` 通过；`npm run build` 成功

## 非目标（本版不做）

可调球数 / 壳半径 UI、会动的出口、障碍迷宫、音效、MediaRecorder 内录、后端与登录。
