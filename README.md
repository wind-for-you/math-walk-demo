# 随机游走 3D 演示

面向自媒体的三维轴对齐随机游走可视化：自动 24 秒循环，竖屏可直接系统录屏。

## 技术栈

Vite + TypeScript + Three.js + Vitest

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址。

```bash
npm test      # 纯逻辑单测
npm run build # 静态产物到 dist/
npm run preview
```

## 使用

- 打开即自动播放（intro → walk → compare → reset，共 24 秒循环）
- `?seed=42` 锁定种子，方便复录同一条
- 点击画面或按空格：换种子重跑（并写入 URL）
- 默认竖屏 9:16 构图；桌面可拉横窗预览

## 默认参数

| 项 | 值 |
|----|----|
| 循环 | 24s |
| 步数 N | 320 |
| 步长 | 0.08 |
| 方向 | ±x ±y ±z 等概率 |
