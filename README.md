# 三个单摆，谁先砸碎花瓶？

三个长度不同的带阻尼单摆，从同一初始角同时释放，摆球首次进入花瓶碰撞半径即「砸中」。最短摆周期最短、先到先赢；没有抢到的摆继续摆动，阻尼把振幅慢慢收掉。单圈约 28 秒自动循环，竖屏 9:16 可直接系统录屏。

## 技术栈

Vite + TypeScript + Three.js + Vitest

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址。

```bash
npm test      # 纯逻辑单测
npm run build # 静态产物到 dist/
npm run preview
```

## 玩法与使用

- 打开即自动播放：intro 2s 抬摆 → race 20s 慢放竞速 → result 4s 排行 → reset 2s 淡出，共 28 秒循环
- 三摆同角释放（θ₀ = 1.0 rad ≈ 57°），摆长 2.5 / 2.8 / 3.1 m；颜色为青 / 琥珀 / 粉
- 摆球中心到花瓶中心 ≤ 0.22 即「砸中」；第一个砸中的摆定格，花瓶碎裂闪光
- 20 秒竞速段是 2.4 秒物理时间的约 8.3× 慢放；HUD 显示物理秒数并标注慢放
- HUD 赛间淡显每摆周期 T≈2π√(L/g)，结果页给出颜色、摆长与砸中时间排行
- 点击画面或按空格：换 seed 重赛（并写入 URL）
- `?seed=42` 锁定：同 seed 的镜头运动可复现，循环时复播
- 无 `seed` 参数时，每圈自动换新 seed；v1 物理参数固定，seed 只影响镜头相位，三摆结果始终一致
- 默认竖屏 9:16 构图；桌面可拉横窗预览

## 默认参数

| 项 | 值 |
|----|----|
| 循环 | 28s（intro 2 / race 20 / result 4 / reset 2） |
| 摆数 | 3 |
| 摆长 L | 2.5 / 2.8 / 3.1 m |
| 释放角 θ₀ | 1.0 rad（约 57°） |
| 重力 g | 9.8 m/s² |
| 阻尼 γ | 0.4 s⁻¹ |
| 花瓶位置 | (-0.6, 0.8) |
| 命中半径 | 0.22 |
| 物理赛程 | 2.4s（铺满 20s 竞速段，慢放约 8.3×） |
| 积分 | 半隐式欧拉，dt = 1/240 s |
| 预期砸中时间 | 0.73 / 1.08 / 1.50 s（青 / 琥珀 / 粉） |

## 验收清单

- [ ] 打开自动播放，单圈约 24–30s 并循环
- [ ] 竖屏可录；标题、秒数与结果在安全区
- [ ] 三摆同角释放、长度不同；短摆先砸中花瓶并定格闪光
- [ ] 阻尼可见（后续摆幅逐渐衰减）
- [ ] 同 seed 可复现；点击 / 空格换 seed；`?seed=` 可锁
- [ ] `npm test` 通过；`npm run build` 成功
